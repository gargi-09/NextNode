Career intelligence that reasons over a skills graph.

NextNode parses resumes and job descriptions with an LLM, maps every skill onto a curated ontology in Neo4j, and computes deterministic, explainable skill gaps and prerequisite-aware learning roadmaps. A team of agents turns that into a reviewed curriculum.

◆

Deterministic scoring

The LLM only reads text. Fit scores come from graph queries and fixed, versioned rules, so the same input always gives the same, explainable answer.

⬢

Strict skill ontology

Every name resolves to a canonical skill or alias ("k8s" → Kubernetes) or is held for review. The LLM can never invent graph nodes.

⚡

Built for free tiers

A global Gemini rate limiter, content-hash caching and a Neo4j circuit breaker keep it running on permanent free tiers.

Agent simulation

Pick a candidate, adjust their skills, then run the agents. This runs entirely in your browser: the scoring is a faithful port of NextNode's Python rules over the real ontology. Parsing is mocked and the activities are templated; in the full system a self-hosted Qwen3 model on vLLM does those steps.
